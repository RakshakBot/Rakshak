Rakshak is made for teams that need practical safety tools without turning server management into guesswork. Permission-based access, staff-only controls, configurable modules, clear logs, and the Support Server help owners and moderators keep decisions visible and manageable.

Responsible Data Use

Designed around least privilege and enabled features.

Rakshak only uses Discord data and gateway intents required for enabled features. Message content is processed only for features such as prefix commands, automod, spam protection, moderation filters, AI/chatbot channels, autoresponders, and security detection.

Rakshak follows least privilege.
Member data is used for security, moderation, autorole, welcome/join flows, logs, invite tracking, and role/member protection.
Presence or activity data may be used only for enabled features such as status or vanity role systems, streaming notifications, or status-related commands.
Rakshak does not sell user data.
Rakshak does not use message content for advertising or profiling.
Rakshak does not use user data, server data, message content, or AI/chatbot interactions to train AI models.
Server logs and settings are intended for server owners and authorized staff.
