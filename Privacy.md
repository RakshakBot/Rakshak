# Rakshak Privacy Policy

Website page: https://RakshakBot.github.io/Rakshak/privacy-policy/

Last updated: May 31, 2026

## Introduction

Rakshak is a Discord bot that provides security, anti-nuke, moderation, logging, automod, ticket, and utility features for Discord servers.

This Privacy Policy explains what Rakshak may process, why that information is used, how access is limited, and how users or server owners can request deletion of applicable stored data.

## Our Approach to Privacy

Rakshak follows least privilege. The bot is designed to request and use only the Discord permissions, data, and gateway intents needed for enabled features to work.

Discord servers can contain private community conversations and sensitive moderation context. Rakshak uses server information only for bot functionality, security, moderation, support, abuse prevention, and service operation.

Rakshak does not sell user data. Rakshak does not use message content for advertising or profiling.

## Data Rakshak May Process

Depending on the features enabled in a server, Rakshak may process or store Discord-related information such as Discord user IDs, server IDs, channel IDs, role IDs, message IDs, command usage records, server settings, security settings, moderation settings, logging settings, automod settings, ticket settings, premium access records, and moderation or security event records.

Rakshak does not intentionally collect Discord passwords, Discord tokens, payment card details, private credentials, home addresses, or phone numbers.

## Message Content

Rakshak processes message content only for enabled features that require it, such as prefix commands, automod, spam protection, moderation filters, and security detection.

Message content is used only for the feature that requires it. Rakshak does not use message content for advertising, profiling, or unrelated analytics.

Where possible, Rakshak uses Discord interactions, slash commands, buttons, select menus, mentions, and other options that reduce the need to access message content.

## Privileged Intents

Rakshak may use Discord privileged gateway intents when they are necessary for core bot features.

These intents may support security, moderation, logging, automod, member event handling, command handling, and server protection systems. Rakshak follows least privilege by requesting only the intents needed for its functionality.

## How Data Is Used

Rakshak uses data to provide and maintain bot features, protect servers from raids and abuse, detect suspicious server actions, apply configured moderation or security actions, manage settings, operate ticket and utility features, manage premium access, prevent abuse of Rakshak, and handle troubleshooting or support.

## Data Visibility and Access Control

Access to stored bot data is limited to the bot owner and authorized maintainers who need access to operate, secure, or support Rakshak.

Inside Discord servers, Rakshak is intended to show server-specific configuration, logs, and moderation information only to users with appropriate Discord permissions, such as the server owner, administrators, or authorized moderators.

Where possible, server-specific information is restricted to users with appropriate permissions.

## Data Sharing

Rakshak does not sell, rent, or trade user data.

Rakshak does not share user data with advertisers, data brokers, or unrelated third parties. Data may be processed by trusted hosting, database, or infrastructure providers only when necessary to operate Rakshak.

Information may also be retained or disclosed if required for safety, abuse prevention, dispute handling, legal requirements, or platform requirements.

## Data Retention

Rakshak keeps data only as long as reasonably needed to provide features, maintain server configuration, support moderation and security logs, manage premium access, prevent abuse, or handle support requests.

Server configuration data may remain stored until the server owner resets the configuration, removes the bot, or requests deletion.

Message content is not permanently stored unless it is required by an enabled moderation, logging, security, or automod feature.

Valid deletion requests are normally reviewed and processed within 30 days unless retention is needed for safety, dispute handling, abuse prevention, legal requirements, or platform requirements.

## Personal Information

Rakshak does not intentionally collect sensitive personal information such as home addresses, phone numbers, payment card details, or government identification.

If a user provides personal information during a support request, access is limited to the people handling that request.

## Data Deletion Requests

Users and server owners can request deletion of applicable stored Rakshak data.

Support Server: https://discord.gg/EwhewfZNbT  
Email: rakshakbot@gmail.com

Please include your Discord User ID, the Discord Server ID if the request is server-related, a short description of the data you want deleted, and proof of server ownership or authorized administrator status if the request is for server-wide data.

## Security

Rakshak takes reasonable steps to protect bot data, credentials, and configuration.

Bot tokens, API keys, database credentials, and private configuration values are not intentionally made public. Access to production systems and stored data is limited to authorized maintainers.

## Children's Privacy

Rakshak operates on Discord and is intended to be used in accordance with Discord's own terms and age requirements.

Rakshak does not knowingly collect personal information from children beyond what is necessary to operate Discord bot features.

## Changes to This Policy

This Privacy Policy may be updated when Rakshak features, security practices, platform requirements, or legal requirements change.

Updates will be posted on the website with a new "Last updated" date.
