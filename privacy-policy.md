# Rakshak Privacy Policy

Last updated: May 31, 2026

Rakshak is a Discord bot that provides server security, anti-nuke protection, moderation, logging, automod, ticket, and utility features.

This Privacy Policy explains what information Rakshak may process, why it is used, how access is controlled, and how users or server owners can request deletion of stored data.

## 1. Our Approach to Privacy

Rakshak is designed around the principle of least privilege. This means Rakshak only requests and uses the Discord permissions, data, and gateway intents that are required for its enabled features to work properly.

Discord servers are often private community spaces. We treat server data with care and use it only for bot functionality, safety, moderation, security, and support purposes.

Rakshak does not sell user data. Rakshak does not use collected data for advertising, user profiling, or unrelated analytics.

## 2. Data Rakshak May Process

Depending on the features enabled in a server, Rakshak may process or store the following types of Discord-related data:

- Discord user IDs
- Discord server IDs
- Channel IDs
- Role IDs
- Message IDs
- Command usage records required for cooldowns, abuse prevention, or bot operation
- Server configuration settings
- Anti-nuke and security settings
- Moderation settings
- Logging settings
- Automod settings
- Ticket system settings
- Premium or access-related records
- Moderation and security event logs, such as bans, kicks, timeouts, role updates, channel changes, webhook changes, bot joins, and similar safety events

Rakshak does not collect Discord passwords, Discord tokens, payment card details, private credentials, home addresses, or phone numbers.

## 3. Message Content

Rakshak may process message content only when it is required for enabled features, such as:

- Prefix command handling
- Automod
- Spam protection
- Moderation filters
- Server safety checks
- Security and anti-abuse detection

Message content is used only for the feature that requires it. Rakshak does not use message content for advertising, profiling, or unrelated purposes.

Where possible, Rakshak uses Discord interactions, slash commands, buttons, select menus, mentions, and other alternatives that reduce the need to access message content.

## 4. Privileged Intents

Rakshak may use Discord privileged gateway intents when they are necessary for core bot features.

These intents may be used for security, moderation, logging, automod, member event handling, command handling, and server protection systems.

Rakshak follows the principle of least privilege by requesting only the intents needed for its functionality.

## 5. How Data Is Used

Rakshak uses data only to provide and maintain bot features, including:

- Protecting servers from raids, nukes, spam, and abuse
- Detecting suspicious server actions
- Applying configured moderation or security actions
- Restoring or logging protected server changes
- Managing server settings
- Running automod and moderation tools
- Operating ticket and utility systems
- Managing premium or feature access
- Preventing abuse of the bot
- Troubleshooting and support

## 6. Data Visibility and Access Control

Access to stored bot data is limited to the bot owner and authorized maintainers who need access to operate, secure, or support Rakshak.

Inside Discord servers, Rakshak shows server-specific configuration, logs, and moderation information only to users with appropriate Discord permissions, such as the server owner, administrators, or authorized moderators.

Rakshak is designed so that sensitive server information is not shown to regular members unless the server configuration or Discord permissions allow it.

## 7. Data Sharing

Rakshak does not sell, rent, or trade user data.

Rakshak does not share user data with advertisers, data brokers, or unrelated third parties.

Data may be processed by trusted hosting, database, or infrastructure providers only when necessary to operate Rakshak.

## 8. Data Retention

Rakshak keeps data only as long as reasonably needed to provide its features, maintain server configuration, support moderation and security logs, manage premium access, prevent abuse, or handle support requests.

Server configuration data may remain stored until the server owner resets the configuration, removes the bot, or requests deletion.

Message content is not permanently stored unless it is required by an enabled moderation, logging, security, or automod feature.

When a valid deletion request is received, we aim to review and remove applicable data as soon as reasonably possible, normally within 30 days unless retention is required for abuse prevention, safety, dispute handling, or legal reasons.

## 9. Personal Information

Rakshak does not intentionally collect sensitive personal information such as home addresses, phone numbers, payment card details, or government identification.

If a user provides personal information during a support request, access is limited to the people handling that request.

## 10. Data Deletion Requests

Users and server owners can request deletion of stored Rakshak data.

To request deletion, contact us through:

Support Server: https://discord.gg/EwhewfZNbT  
Email: rakshakbot@gmail.com

Please include:

- Your Discord User ID
- The Discord Server ID, if the request is related to a server
- A short description of the data you want deleted
- Proof of server ownership or authorization, if the request is for server-wide data

## 11. Security

We take reasonable steps to protect Rakshak data and bot credentials.

Bot tokens, API keys, database credentials, and private configuration values are not intentionally made public.

Access to production systems and stored data is limited to authorized maintainers.

## 12. Children’s Privacy

Rakshak operates on Discord and is intended to be used in accordance with Discord’s own terms and age requirements.

Rakshak does not knowingly collect personal information from children outside what is necessary to operate Discord bot features.

## 13. Changes to This Policy

We may update this Privacy Policy when Rakshak features, security practices, or legal requirements change.

Updates will be posted on this page with a new “Last updated” date.
